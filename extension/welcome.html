cctabgaze 已安裝

這一頁只在第一次安裝時出現。之後的設定都在插件圖示的懸浮視窗裡。

只在電腦之間旁觀

不用再做任何事。這台預設是 host；要旁觀的那台點插件圖示，按「Viewer」。

要讓手機連進來（只有 host 這台 Mac 要做）

  1. 在專案資料夾執行 bun run setup。它會把信令伺服器裝成常駐服務，結束時印出 token。插件不能替你執行本機的指令，所以這一步要自己來。
  2. 用 Tailscale 提供 HTTPS：tailscale serve --bg --https=8443 8790
  3. 把伺服器位址與 token 填在下面，按儲存。

設定存在這台，不同步。之後要改：插件圖示 →「信令伺服器（手機 PWA）」。
